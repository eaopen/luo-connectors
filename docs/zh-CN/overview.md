# luo-connectors 项目概览

`luo-connectors` 是洛律（Luo Rhythm）的公开集成层。

## 品牌

- 命名：洛律（Luo Rhythm），简称“洛（Luo）”
- Slogan：流转中的秩序。

## 职责边界

- 插件与连接器（如 Obsidian、Notion、CLI 等）
- 面向集成方/用户的公开文档

## 当前状态

规划与骨架阶段，暂无可运行实现。

## 迭代计划

- 目标：1 天内上线 v1，然后以天 / 小时为单位快速迭代
- v1 必包含 OpenClaw skill

## 开发/运行

环境要求：

- Node.js 18+

```bash
npm run dev
```
